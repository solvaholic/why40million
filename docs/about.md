# About

**Why 40 Million?** is a weekly blog by [@solvaholic](https://github.com/solvaholic)
that chases the suspiciously recurring "40 million" figure across news,
culture, and statistics.

## How posts get made

1. A weekly GitHub Actions cron asks Copilot to research a fresh angle
   and draft a post.
2. The workflow opens a pull request with the draft and its sources.
3. A human reviews, fact-checks, edits, and merges.
4. A separate workflow builds the site with MkDocs Material and deploys
   to GitHub Pages.

## Editorial rules

- Every "40 million" claim is sourced inline. No source, no claim.
- AI drafts are starting points, not final copy. A human edits before merge.
- Errors get corrected with a visible note on the post.
